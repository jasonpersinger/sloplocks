- Main layout:

  - Filter nav
  - Main feed that swaps between dashboard cards and pick cards
  - Footer stats rail
- Pick UI structure:
  - Kicker row with sport and timestamp
  - Odds block
  - Team/title row with market tag
  - Metric grid
  - Edge meter
  - Optional blurb
- Dashboard UI structure:
  - Status rail
  - Stack of text-heavy dashboard cards
  - Footer summary metrics

### Redundant, unclear, or bloated UI elements

- The shell already uses a terminal aesthetic, but several labels are more performative than informative: `MODE: EDGE_DETECTION`, `STATUS: NOMINAL`, `SYS_DATA_BLOCK`, `SLATE_SNAPSHOT`, `TS_BUILD`.
- Several class hooks used by JS-rendered markup are not styled at all, which makes the structure feel unfinished.
- Dashboard cards are dense but visually flat; they read like raw dumps rather than intentional monitor panels.
- Empty and error states use more text than needed for a data board.
- The service worker caches JetBrains Mono, but the page imports Share Tech Mono. That is an aesthetic dependency mismatch.
- `manifest.json` still describes the app as an EPL predictions finder, which no longer matches the multi-sport UI.

### Dependencies and assets tied to the current aesthetic

- Google Fonts import in `index.html` for `Share Tech Mono`
- Service worker font cache entry in `sw.js` for JetBrains Mono
- PWA icons in `icons/`
- `manifest.json` theme and app metadata
- Data fetch pipeline from `data/dashboard.json` and `data/<sport>/predictions.json`

## Phase 2: Plan

### UI direction

- Keep the terminal/CRT direction, but make it more coherent and less noisy.
- Use a darker phosphor monitor treatment: black-green palette, stronger frame, subtle glow, scoped scanline overlay, and clearer hierarchy.
- Keep `Share Tech Mono` with system monospace fallback.
- Add a cursor blink treatment only on active or loading interactive states, not everywhere.

### Copy changes

- Cut non-informational shell language.
- Replace system-flavored filler labels with terse data labels.
- Keep dynamic placeholders and diagnostic values intact.

### Component changes

- Restyle:
  - Header
  - Nav tabs
  - Status rail
  - Pick cards
  - Dashboard cards
  - Footer stats rail
- Restructure:
  - Header into a tighter title + utility meta block
  - Card headers and dashboard text blocks for better alignment
- Remove or reduce:
  - Overwritten cyber flavor copy that does not help interpretation
  - Inconsistent unused styling gaps

### New CSS variables and utilities

- Add monitor surface, glow, shadow, and muted text variables.
- Add utility treatments for panel chrome, status chips, preformatted dashboard lines, and loading cursor states.
